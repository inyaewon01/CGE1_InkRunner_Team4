1. Title
게임을 실행하면 → Title 씬을 불러온다.  

Title 씬 로딩이 완료되면 → 게임 시작, 조작 안내, 종료 버튼을 표시한다. 
조작 안내 버튼을 클릭하면 
→ 좌클릭: 선택한 먹 사용 
→ 우클릭: 검은 먹 / 흰 먹 전환 
ESC: 일시정지 를 표시한다.  

게임 시작 버튼을 클릭하면 
→ 중복 클릭을 막는다. 
→ Play 씬을 불러온다. 

종료 버튼을 클릭하면 
→ 게임을 종료한다.


2. Play

Play 씬 로딩이 완료되면
→ 게임 상태를 '준비'로 설정한다.
→ 점수와 플레이 시간을 0으로 설정한다.
→ 이동 속도와 난이도를 초기값으로 설정한다.
→ 플레이어의 최고 점수를 오른쪽 상단에 보여준다.
→ 잉크 게이지를 최대로 채운다.
→ 선택한 먹을 검은 먹으로 설정한다.
→ 캐릭터를 시작 위치에 배치한다.
→ 안전한 시작 플랫폼과 앞쪽 구간을 생성한다.
→ 이전 플레이의 선, 삭제 상태, 회복 대기를 초기화한다.
→ 3초 카운트다운을 표시한다.

카운트다운 중에는
→ 맵 이동, 점수 증가, 잉크 사용, 점프를 막는다.

카운트다운이 끝나면
→ 카운트다운 UI를 숨긴다.
→ 게임 상태를 '플레이 중'으로 변경한다.
→ 달리기와 입력 처리를 시작한다.

게임 상태가 '플레이 중'이면
→ 랜덤한 장애물과 플랫폼을 오른쪽 화면 밖에서 생성시킨다.
→ 맵과 장애물을 정해진 속도로 왼쪽으로 이동시킨다.
→ 생성한 검은 잉크 길도 같은 속도로 이동시킨다.
→ 캐릭터는 화면의 기준 가로 위치를 유지하며 달린다.
→ 플레이 시간을 누적한다.
→ 플레이 시간 1초마다 점수를 10점씩 올린다.

캐릭터가 N초 이상 공중에 있으면
→ 게임오버 상태로 만든다.

캐릭터가 바닥 또는 그린 길 위에 착지하면
→ 계속 진행한다.

플레이 중 마우스 기본상태
→ 검은 잉크 상태로 시작한다.

플레이 중 마우스 오른쪽 버튼을 한 번 누르면
→ 진행 중인 붓질을 끝낸다.
→ 선택한 먹을 검은 잉크 ↔ 흰 잉크로 전환한다.
→ 커서와 HUD에 현재 먹 종류와 사용량을 표시한다.
→ 먹을 전환해도 게이지는 초기화하지 않는다.

검은 잉크가 선택된 상태에서
마우스 왼쪽 버튼을 누르고 드래그하면
→ 사용 가능한 잉크와 그리기 가능 영역을 확인한다.
→ 마우스 경로를 따라 검은 선을 생성한다.
→ 생성한 선에 캐릭터가 밟을 수 있는 충돌 영역을 만든다.
→ 새로 그린 길이에 비례해 잉크를 차감한다.
→ 남은 잉크로 그릴 수 있는 길이까지만 생성한다.

흰 잉크가 선택된 상태에서
→ 장애물 위로 마우스 왼쪽을 클릭하면 장애물은 삭제된다.
→ 콜라이더 뿐만 아니라 오브젝트 자체를 안보이게 처리한다.

UI 위 또는 캐릭터 몸과 겹치는 영역에서는
→ 선을 생성하지 않는다.
→ 잉크를 차감하지 않는다.

왼쪽 버튼을 놓거나 잉크가 고갈되면
→ 현재 선의 생성을 끝낸다.
→ 이미 생성한 길은 그대로 유지한다.

잉크를 사용하고 N초 후
→ 속도에 비례해서 자동회복을 진행한다.


2-1. 잉크

그리기 또는 장애물 제거가 실제로 수행되면
→ 잉크를 차감한다.
→ 회복 대기 시간을 처음부터 다시 센다.

잉크가 0이 되면
→ 추가 잉크 사용을 막는다.
→ 게임은 계속 진행한다.
→ 이미 그린 길과 제거한 장애물의 상태는 유지한다.

잉크를 실제로 사용하지 않은 시간이 0.5~1초에 도달하면
→ 정해진 속도로 잉크를 회복한다.

잉크가 최대치에 도달하면
→ 회복을 멈춘다.

회복한 잉크로 사용 조건을 충족하면
→ 다시 그리거나 제거할 수 있다.


2-2. 무한 맵

화면 앞쪽에 준비된 구간이 부족해지면
→ 현재 난이도에 맞는 다음 구간을 랜덤으로 선택한다.
→ 플랫폼과 장애물을 화면 오른쪽 밖에 배치한다.

구간을 연결할 때
→ 플랫폼 간 거리와 높이 차이가 허용 범위인지 확인한다.
→ 먹 사용·회복과 점프로 통과 가능한 조합인지 확인한다.
→ 대응할 시간 없이 위험물이 등장하지 않게 한다.

정해진 진행 기준에 도달하면
→ 난이도를 한 단계 높인다.
→ 허용 범위 안에서 플랫폼 간격과 어려운 패턴의 비중을 늘린다.
→ 검은 먹의 길이당 비용과 흰 먹의 제거 비용은 유지한다.

플랫폼, 장애물, 그린 길이 화면 뒤쪽으로 충분히 벗어나면
→ 해당 오브젝트를 회수한다.
→ 재사용할 때 제거 상태와 충돌 판정을 초기화한다.


3. Score

Score 씬 로딩이 완료되면
→ 이번 점수와 최고 점수를 표시한다.
→ 다시 시작, 타이틀, 종료 버튼을 표시한다.

다시 시작 버튼을 클릭하면
→ Play 씬을 새로 불러온다.
→ 초기화와 카운트다운부터 다시 진행한다.

타이틀 버튼을 클릭하면
→ Title 씬으로 이동한다.

종료 버튼을 클릭하면
→ 게임을 종료한다.
